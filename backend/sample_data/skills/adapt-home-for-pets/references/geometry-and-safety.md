# 适宠化几何与落位规则

## 硬约束

- 家具在房间内，不穿墙、不重叠固定设施，不挡门窗、检修和人的疏散。
- 保留人类主通道，同时给宠物提供不被堵死的退路。
- 不在开放窗、阳台或栏杆边新增能吸引攀爬/跳跃的家具。
- 高柜、爬架、笼架、水族箱和落地灯检查稳定、承重和防倾倒。
- 食水、排泄、睡眠和人的备餐区域按物种和卫生要求分区。
- 水体、电线、加热器和宠物啃咬/泼洒范围不能形成组合风险。
- 商品无完整尺寸时不生成坐标；有尺寸也只生成未购买预览。

## 行为扩大范围

猫的跳跃、狗的推撞、兔的钻缝、鸟的飞行会让二维地面可达性失真。JSON 没有高度、门窗开合、网体和宠物能力时，把立体可达性标为未知并要求现场确认。

## 候选动作顺序

1. 隔离有毒、易吞、热、电和逃逸点；
2. 收线、封垃圾和清洁用品；
3. 防滑、防倾倒、防逃的待实施措施；
4. 微移小件或资源点 0.05-0.30 m；
5. 建立休息、活动、食水和排泄分区；
6. 增加家具保护与合法抓咬替代；
7. 推荐目录商品；
8. 仅为 P0/P1 且轻量措施无效时提出大型家具重排。

大型重排不自动应用，必须列出前后几何、宠物退路、人的通道、受影响家具和确认要求。

## 商品摆放预览

要求尺寸单位完整、物种匹配、房间明确、边界碰撞通过、通道和退路通过，并核验稳定、承重、水电、逃逸和资源分区。预览只写分析区。

## 局限

二维 JSON 不能证明网体强度、墙体固定、材料毒性、真实跳跃、抓咬耐久、气味、噪声或多宠行为。输出现场核验清单，不给绝对安全结论。
