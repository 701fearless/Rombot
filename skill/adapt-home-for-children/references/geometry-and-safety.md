# 适儿化几何与落位规则

## 硬约束

- 所有家具占地位于所属房间内，不穿墙、不重叠固定设施。
- 不侵入门扇、抽屉、柜门、窗扇、设备检修和疏散区。
- 不缩窄项目 `minPassage`，同时保留照护者快速到达儿童的路线。
- 不在窗、阳台、栏杆和楼梯旁新增可攀爬踏脚物。
- 不在床、婴儿床、游戏垫和高脚椅上方放悬挂重物。
- 电器、热源、水体、绳线和小件必须结合儿童可达性审查。
- 商品无尺寸时不生成落位；有尺寸也只生成未购买的摆放预览。

## 儿童可达范围

只有 JSON 或现场测量提供身高、家具高度和位置时才做数值判断。没有数据时使用 `unknown`，不要伪造固定“安全高度”。儿童可能借助椅子、抽屉和玩具扩大可达范围，因此单纯放高不是永久措施。

## 候选动作顺序

1. 移除小物、绳线和杂物；
2. 修改使用状态或收纳位置；
3. 加锁、固定、防滑或软角的待实施措施；
4. 微移小型家具 0.05-0.30 m；
5. 建立清晰活动区和照护路线；
6. 推荐目录商品；
7. 仅为 P0/P1 且轻量措施无效时提出大型家具重排。

大型家具重排不得自动应用，必须包含前后几何、受影响家具、轻量替代方案为何不足和 `requiresUserConfirmation: true`。

## 商品摆放预览

预览必须同时满足完整尺寸、单位一致、目标房间明确、边界和碰撞通过、门窗/通道通过、儿童风险属性足够。预览写入分析区，不加入现有 `furniture`、`assets` 或 `placements`。

## 校验局限

二维 JSON 不能验证固定件施工、墙体承载、产品召回、真实栏杆间距、儿童行为、材料迁移、阻燃和环保性能。明确列出现场或商品资料核验项。
