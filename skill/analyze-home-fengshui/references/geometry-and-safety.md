## 坐标规范

修改前确认单位、全局或局部坐标、原点、x/y 轴、旋转零度、顺逆时针、矩形 x/y 的锚点和北向角。任一关键含义不明时不改坐标，只写相对描述。

## 硬约束

候选变更必须全部满足：

1. 家具占地所有顶点位于所属房间或允许区域内；
2. 不与墙、柱、固定柜、洁具、炉灶、设备和其他落地家具重叠；
3. 不进入门扇、抽屉、柜门、窗扇和设备检修开启区；
4. 不覆盖出口、消防、通风、地漏、暖气、插座维护空间和主要采光口；
5. 不把主通道净宽降到 `constraints.minPassage` 以下；
6. 床和高频座位至少保留一条可达路线；
7. 水体远离未防护电源，热源远离可燃物；
8. 悬挂或桌面物件有 `supportSurfaceId` 或明确安装条件；
9. 儿童、宠物、轮椅和租房约束全部满足；
10. 不修改结构、硬装、厨卫、固定设施、门窗和管线。

结构字段黑名单至少包括 `shell`、`walls`、`columns`、`beams`、`doors`、`windows`、`fixedFixtures`、`plumbing`、`gas`、`electricalWiring`、`wetAreas`。允许增加只读分析引用，不允许改变几何或状态。

## 软约束

在硬约束通过后优化主路线、入口第一视线、背部支撑、看见入口但避开高频直冲、家具与房间主轴、采光、窗帘、清洁和维护空间。软约束不能推翻硬约束。

## 变更搜索

按最小扰动顺序搜索：

1. 不移动，仅清理、开灯、遮镜或收纳；
2. 旋转小件 5、10、15、20、30 度；
3. 沿墙或坐标轴微移 0.05、0.10、0.15、0.20、0.30 m；
4. 复用现有小件；
5. 在已知空闲区新增一个小件；
6. 单件大型家具小幅移动；
7. 生成但不应用家具大改方案。

每次只改变一个变量并重新校验。收益相近时选择扰动更低的方案：

```text
disturbance = moved_item_count * 4
            + total_translation_m * 2
            + total_rotation_deg / 30
            + added_item_count * 2
            + removed_item_count
```

该分数只比较方案，不表示吉凶。

## 家具大改门槛

以下任一属于家具大改：大型家具平移超过其短边 25% 或 0.60 m；旋转超过 45 度；同时移动两件以上大型家具；跨房间移动；改变主要功能区组织。

它只能出现在 `proposedMajorFurniturePlan`，不得自动应用。必须列出明显问题与至少两项证据、轻量方案为何不足、家具和距离、新坐标、变更前后校验、工作量、恢复方式，并标记 `requiresUserConfirmation: true`。

纯方位、流年、颜色或装饰偏好永远不足以触发家具大改。

## 新增物件落位

新增落地物件必须具备尺寸、位置、朝向、房间、移动性和安全特征。先找已知空闲区，再排除开启区、通道、检修区和高频区，检查光照、承载、水电、儿童与宠物，增加至少 0.05 m 容差并运行校验。任一条件无法验证时降级为 `recommended`。

桌面物件使用承载面局部坐标，不伪装为落地坐标：

```json
{
  "mountType": "surface",
  "supportSurfaceId": "console-1",
  "localPosition": { "u": 0.75, "v": 0.5 },
  "footprint": { "width": 0.18, "depth": 0.18 }
}
```

承载面尺寸未知时不自动新增。

## 校验局限

二维几何不能确认家具高度与承重、暗管、电路燃气、真实步态与多人拥挤、光照风速噪声气味、现场门窗状态和图纸误差。脚本通过仅表示在给定二维数据和规则内未发现错误，不是工程安全认证。
