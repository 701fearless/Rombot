# 给后端同学：3 分钟跑起前端效果

## 零依赖预览（推荐，不用 npm install）

已内置最新构建产物 `dist/` 和零依赖静态服务器，只要有 Node.js（≥18）：

```bash
node scripts/preview-h5.cjs 10086
# 浏览器打开 http://localhost:10086/
```

- 手机看：手机连同一 Wi-Fi，访问 `http://<电脑局域网IP>:10086/`（桌面端已限宽手机画幅，真机访问即是手机效果）。
- 数据全部为本地 mock（`src/mock/` + `src/services/`，签名即接口契约，可直接照此定接口）。

## 想改代码重新构建（可选）

```bash
pnpm install        # 或 npm install
pnpm build:h5       # 产物到 dist/
node scripts/preview-h5.cjs 10086
```

注意：`pnpm dev:h5` 的 webpack-dev-server 在本项目（中文路径）下有白屏问题，预览一律走「build + preview-h5.cjs」。
